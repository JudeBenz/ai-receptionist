# AfterRing pitch video

`afterring-pitch-1080p.mp4` (1920x1080) and `afterring-pitch-720p.mp4` (1280x720, small enough to
attach to an email) are the 85-second pitch sent to owners after a cold call. Everything in them is
generated by the scripts in this folder: no stock footage, no licensed music, no recorded voices.

What it covers, in order: a shop phone ringing out and the caller moving on; the one-line problem;
what AfterRing does (answers only after about 15 seconds unanswered, or after hours); a simulated
booking call with the AI disclosure and the recording notice; the email summary and calendar event
the owner receives; what it is not (never replaces staff, never cold-calls, you keep your number);
the 30-day pilot and the Growth plan at $497 a month; the end card with the demo number, email and
booking link.

## How it is built

| Step | Tool | File |
|------|------|------|
| Voices (narrator, caller, receptionist) | Microsoft Edge neural voices through `msedge-tts` | `build.mjs` |
| Music bed and sound effects | Additive synthesis in plain JavaScript | `lib/audio.mjs` |
| Timeline (scene lengths follow the audio) | `build.mjs` writes `build/timeline.json` | `build.mjs` |
| Frames (motion graphics, text, flash cuts) | PowerShell 5.1 with System.Drawing (GDI+) | `render-frames.ps1` |
| Encoding | `ffmpeg-static` (H.264 + AAC) | `build.mjs` |

Intermediate files go to `build/` (ignored by git): cached voice clips in `build/tts/`, the mixed
track `build/mix.wav`, the timeline, and one PNG per frame in `build/frames/`.

## Re-rendering

Needs Node 18 or later, Windows PowerShell 5.1 (for GDI+) and an internet connection the first time
each voice line is synthesised.

```bash
cd video
npm install
npm run build
```

`npm run build` runs everything; a full build takes a few minutes, most of it frame rendering.
Partial runs:

- `npm run audio`: voices, timeline and mix only (fast; voice lines are cached by text and voice).
- `npm run frames`: frames only, from the existing `build/timeline.json`.
- `npm run encode`: MP4s only, from the existing frames and mix.
- `node build.mjs --jobs 4`: number of PowerShell renderers to run in parallel (default: CPU count, up to 8).

## Changing the script

Edit `script.json`. Each scene has:

- `lines`: what is spoken, in order, with the `speaker` (`narrator`, `receptionist` or `caller`) and an
  optional `gap` in seconds before the line. Scene length is computed from the audio, so a longer line
  simply makes the scene longer.
- `text`: everything shown on screen for that scene. Square-bracket placeholders such as
  `[demo_number]`, `[email]` and `[booking_link]` are filled from `../business/brand.json` at build
  time, so update the brand file rather than the script when those change.
- `events`: named moments the renderer animates to (a hang-up, a card sliding in). `after` is `start`
  or `line:N` (the end of line N); `offset` is in seconds and may be negative.
- `leadIn`, `tail`, `minDuration`: padding in seconds around the lines.

`voices` at the top picks the Edge voice, rate and pitch per speaker. Any `en-US-*Neural` voice works;
keep the three distinct.

`flash` controls the cut between scenes: a few solid frames (`frames`, 3 by default) alternating
through `colors` (white and orange). The first scene has no flash.

Layouts live in `render-frames.ps1`, one `Scene-*` function per scene `type`. Colours and fonts are
at the top of that file: Archivo and Source Sans 3 are used when installed, otherwise Segoe UI, which
is the brand's stated fallback.

## Rules the video keeps

- The receptionist says it is an AI and that the call may be recorded, in its first line.
- The call is labelled "Simulated call" on screen for its whole length, with a note that the voices
  are synthesised. The business in it (Northwind Heating and Air) is the sample from `knowledge/`.
- No statistics appear. The only numbers are the ones already in the deck: 15 seconds, 30 days,
  $497 a month.
- Inbound only: the "what it is not" scene says it never cold-calls and sends no marketing texts.
- The first and last frames carry the logo.

## Known limits

- The Edge voice endpoint occasionally drops a connection; `build.mjs` retries each line up to five
  times. If a line keeps failing, run `npm run audio` again later; finished lines are cached.
- The music bed is a simple synthesised loop. Replace `music()` in `lib/audio.mjs` with any
  royalty-free track decoded through `decodeToFloat()` if a produced bed is wanted later.
